# Playwright E-Commerce Automation Framework

## 📌 Project Overview

This project is a mock E-Commerce web automation testing framework developed using Playwright with JavaScript.

The framework automates important user workflows such as login, product selection, cart operations, checkout, and logout.

## 🛠️ Technologies Used

- Playwright
- JavaScript
- Node.js
- Page Object Model (POM)
- HTML Test Reports
- Git & GitHub
- Cross-Browser Testing
